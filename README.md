O que ela resolve
🔎 Busca por modelo equivalente: digite `RTX 4060 MSI` e veja RTX 4060 de qualquer marca, sem misturar com a 4060 Ti.
🏷️ Novos e usados, com verificação automática de que o filtro de condição realmente foi aplicado.
🚨 Detecção de preços suspeitos (golpes, peças avulsas, anúncios com valor errado).
📈 Histórico de preços salvo localmente, sem servidor e sem coleta de dados.
Bastidores técnicos: motor de correspondência de produtos, leitura de HTML com plano B quando o layout muda, 13 testes automatizados e CI no GitHub Actions. Zero dependências em runtime.
